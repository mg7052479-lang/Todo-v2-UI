# ✅ Todo App

A modern and clean **Todo Application** with a **better UI**, built using **HTML, CSS, and JavaScript**. This app helps users organize their daily tasks efficiently with a smooth and user-friendly interface.

This project focuses on improving **UI/UX design** along with strengthening **JavaScript fundamentals** such as DOM manipulation and event handling.

---

## 🚀 Features

* ➕ Add new tasks easily
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* ✏️ Clean and minimal user interface
* ⚡ Fast and responsive interactions
* 📱 Works smoothly on mobile and desktop

---

## 🎨 UI Highlights

* Modern layout with proper spacing
* Clear visual distinction between completed and pending tasks
* Smooth hover and click effects
* User-friendly design focused on simplicity

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & UI design
* **JavaScript (Vanilla JS)** – App logic & DOM manipulation

## ⚙️ How It Works

1. Type a task into the input field
2. Click **Add** or press Enter
3. Task appears in the list
4. Click on a task to mark it as completed
5. Use the delete option to remove tasks
